# Instagram Dashboard

Panel web para visualizar información autorizada de una cuenta de Instagram.

## Publicar con GitHub Pages
En el repositorio abre Settings > Pages y publica desde la rama main y la carpeta raíz.

## Conexión
El frontend espera un backend HTTPS con un endpoint /api/profile. Las credenciales privadas deben configurarse únicamente en el proveedor del backend y nunca dentro de archivos públicos de GitHub.

Este proyecto no crea seguidores ni automatiza follows para inflar métricas.
